# Sheet Metal Samurai — cover images

Cover frames for the lessons in the Sheet Metal Samurai video library app.
Every file is a still from one of Adam Fleisch's own published videos.

Filenames carry the platform ID of the source video:

    covers/tt-<tiktok video id>.jpg
    covers/ig-<instagram shortcode>.jpg

Served over CDN:

    https://cdn.jsdelivr.net/gh/enngrowth/sms-covers@main/covers/<filename>

540px wide JPEG. 569 files — more than the library uses, so lessons added
later already have a cover available.
